# The STE pilot starts

Myk chose ASD-STE100 style for outward-facing text on 2026-07-26. This is a pilot.

**The problem.** Our prose was dense. Myk had to parse each PR body to find the decision under
it. That work was slow, and it did not get faster with practice.

**The decision.** All text for Myk uses STE style: chat messages, PR bodies, open questions,
the board artifact, journal entries, and commit messages. The rules: write one instruction per
sentence; keep sentences at 20 words or fewer; use active voice; use simple tenses; use no
metaphor; give each word one meaning. Technical names are permitted as domain terms.

**The scope limits.** The spec keeps its dense register. Myk's reason: the dense register can
help the model express complex structure. His condition: every spec idea must translate to STE
when we communicate it to him. The board banner keeps its metaphor. Myk approved that too.

**What we rejected.** We compared the Matt Pocock teaching style on the same five texts. Myk
rejected it for this problem. That style adds engagement. It does not add clarity at a glance,
and it makes the texts longer.

**Why this entry exists.** The ruling lives in chat. CLAUDE.md now carries the rule for lanes
and future sessions. This entry records the comparison and the reasons, which CLAUDE.md does
not carry.
